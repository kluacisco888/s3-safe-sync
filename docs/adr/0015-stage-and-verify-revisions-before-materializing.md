# Stage and verify Revisions before materializing

Authenticated downloads become live Vault files only after the plaintext size and hash match the Revision, a plugin-private temporary file is written and verified, and the current local content still matches the Sync Plan. Replacement renames the old file to a backup before promoting the temporary file. A recovery journal restores the backup or keeps a verified promoted file on the next scan after interruption. Mobile processes one file at a time. Network transfer and decryption still restart after process termination; only final local materialization is currently recoverable.
