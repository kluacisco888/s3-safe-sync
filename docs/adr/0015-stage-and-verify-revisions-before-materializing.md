# Stage and verify Revisions before materializing

Authenticated downloads become live Vault files only after the plaintext size and hash match the Revision, a plugin-private temporary file is written and verified, and the current local content still matches the Sync Plan. The journal records the original content hash; replacement verifies that the file moved to backup still has that hash before promoting the temporary file. Recovery restores a verified backup, keeps a verified promoted file, or stops with the journal and both ambiguous copies preserved for review. Plugin-originated recovery, replacement, move, and deletion operations share one per-Vault mutation lock. Mobile processes one file at a time. Network transfer and decryption still restart after process termination; only final local materialization is currently recoverable.
