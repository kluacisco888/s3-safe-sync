# Migrate from the Remotely Save format

After a final successful Remotely Save run and user review, the user will manually disable Remotely Save and confirm the cutover; the verified desktop Vault then becomes the Migration Baseline. The plugin will read the user's password-protected Rclone Crypt repository from Remotely Save 0.5.25 as needed for migration, then write a user-selected, separate versioned S3 prefix rather than remaining wire-compatible. A local/remote difference, decryption failure, or mixed legacy format stops the read-only migration for explicit review. The legacy prefix remains untouched indefinitely and is only suggested for manual cleanup after 30 days. This preserves existing user data while allowing durable deletion records, stable entry identities, and explicit conflict handling that the legacy format does not represent.
